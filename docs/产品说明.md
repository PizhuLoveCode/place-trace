# 地方经纬

**演示：** https://pizhulovecode.github.io/place-trace/

## 定位

家庭教育向的「地方故事地图」——今晚在家打开，家长和孩子一起，沿地图走完一座湖 / 一座寺的故事。

不是专业考古系统，也不是纯旅游 App；时长约 15–20 分钟，适合共读与行前预习。

## 思路

传统介绍多是文字或介绍牌，缺少空间感：景点之间什么关系、按什么路线讲、家长如何短时间讲完。

做法是把「一座景点」做成可播放的环线故事：地图定位置，内容包定主线，一套产品壳可换多个景点。

## 已有内容

| 内容包 | 说明 |
|--------|------|
| 西湖经纬 | 环湖 12 站，按景点顺序讲述 |
| 灵隐经纬 | 香道 9 站，按参观路线共读 |

顶部可切换内容包；另有可视化编辑页，可改文案与坐标并导出。

## 功能

1. **地图播故事** — 每站对应真实位置，可沿路线前进  
2. **家庭双文案** — 孩子版口语短文 + 家长旁注  
3. **轻互动** — 每站一小题、足迹章、结束小结  
4. **两种节奏** — 「一起听故事」自动播 / 「一起探险」自选站  
5. **语音播报** — 朗读本站故事，可静音  
6. **问一问** — 基于本站资料追问，不编造未写年份  
7. **AI 扩写景点** — 按统一方法生成新内容包，编辑后可预览、导出  

## 和 AI

- **生成：** 快速做出新景点内容包（如西湖 → 灵隐 → 其他）  
- **体验：** 现场「问一问」答疑  

产品负责好看、好懂、适合亲子；AI 负责持续生产与互动讲解。
